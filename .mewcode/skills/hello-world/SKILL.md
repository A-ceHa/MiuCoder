# Hello World

A minimal skill that produces a friendly greeting.

## Instructions

1. Read the user's message for any name or context they provide.
2. Generate a warm, friendly greeting that includes:
   - A cheerful opening (e.g., "Hello", "Hi there", "Hey")
   - The user's name if provided
   - A brief, pleasant remark
3. Keep it short and genuine — no over-the-top enthusiasm, just a nice hello.

## Examples

**Input:** (no name provided)
**Output:** Hello! Hope you're having a great day.

**Input:** name="Alice"
**Output:** Hi Alice! Great to see you — hope you're doing well.
